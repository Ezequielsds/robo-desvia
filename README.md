# Robô desvia obstáculos

Trombot500 🤖
Descrição

O Trombot500 é um robô desenvolvido para aulas de Robótica e Eletrônica, com o objetivo de desviar de obstáculos de forma autônoma. Ele combina conceitos de sensores, motores e lógica de programação para navegar de maneira eficiente pelo ambiente.

Funcionalidades

Detecta obstáculos à frente.

Desvia automaticamente para evitar colisões.

Possível expansão futura com mais sensores ou funcionalidades.
